# Voxel Vault Website Redesign

This is a redesigned website for a company called Voxel Vault.

## Changes Made

*   **New Company Name:** The company name has been changed to "Voxel Vault".
*   **New "Zen" Design:** The website has been redesigned with a "zen" and premium look and feel, using "Manrope" as the primary font. The color palette, spacing, and layout have been adjusted to create a sense of calm and minimalism.
*   **New Logo:** The placeholder logo has been replaced with the new Voxel Vault logo, and it has been properly scaled for display in the header and footer. The blue tint issue in the dark theme has been resolved by using a separate grayscale version of the logo for dark mode.
*   **Dark Theme:** A dark theme is the default theme, with a theme switcher in the header to toggle to a light theme.
*   **Mobile Responsiveness:** The website is now fully responsive and includes a hamburger menu for mobile navigation.
*   **New Pages:**
    *   `careers.html`: A page with job listings.
    *   `about.html`: A page with information about the company and its team.
    *   `blog.html`: A page with placeholder blog posts.
*   **Updated Pages:** All pages have been updated with the new design, theme switcher, and a more detailed footer.
*   **News Section:** A "Latest News" section has been added to the homepage.
*   **Removed Boxes:** The background colors from the project and job listing sections have been removed for a cleaner, more open design.

## How to View the Website

To view the website, simply open the `index.html` file in your web browser.
